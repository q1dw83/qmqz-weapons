# 全民枪战2 武器数据（玩家整理）

从游戏百科截图整理的《全民枪战2》武器属性表，便于查询与筛选。

## 内容

- `weapons.json`：主数据（988 把，48 个系列）
- `shots/`：对应缩略图（与 JSON 中 `截图文件` 字段对应）

## 数据范围

- 只收录 2026-10-10 之前游戏百科里已有的武器，通行证收录到第 59 季。
- 每种武器只登记最高等级版本，一行一把。
- 最高等级不超过 Lv.9 的普通枪支（新手武器）不收录；近战和手雷不受此限制。
- 名字和数值完全相同、只是皮肤不同的武器合并为一行；名字不同的即使数值相同也分开登记。
- 传说级统一记为 Lv.15。

## 字段说明

见 `weapons.json` 的 `columns`。常见字段包括：系列、武器名、武器类型、等级、伤害、射速、精度、稳定、跑动、穿甲、射程、换弹、弹匣容量、备弹数量、英雄/生化/破甲打击、迷宫相关、特殊属性、击败特效、介绍等。

## 使用

直接读取 `weapons.json` 中的 `weapons` 数组即可。
