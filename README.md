# 全民枪战2 武器数据（玩家整理）

从游戏百科截图整理的《全民枪战2》武器属性表，便于查询与筛选。

## 在线浏览

👉 **https://q1dw83.github.io/qmqz-weapons/**

按系列浏览全部武器，支持名称搜索、武器类型筛选、按伤害/射速/精度/穿甲/跑动/英雄打击/弹匣容量排序；点击卡片查看大图（含多皮肤）和完整属性。页面为纯静态（`index.html` + `app.js` + `style.css`），本地可用 `python3 -m http.server` 预览。新增截图后运行 `python3 tools/build_shots_index.py` 更新 `shots_index.json`（缩略图与皮肤图索引）。

## 内容

- `weapons.json`：主数据（988 把，48 个系列）
- `chips.json` / `chips.csv`：芯片名 ↔ 对应武器 ↔ 效果对照（来自天赋属性加成）
- `shots/`：对应缩略图（与 JSON 中 `截图文件` 字段对应）

## 数据范围

- 基础收录截止 2026-10-10（通行证到第 59 季）；**2026-10-22** 追加：通行证第 60 季 **蜮龙·传说**，以及龙系列 **双龙-沙鹰·传说**（替换原最高档 究极双龙-沙鹰改·39）。
- 每种武器只登记最高等级版本，一行一把。
- 最高等级不超过 Lv.9 的普通枪支（新手武器）不收录；近战和手雷不受此限制。
- 名字和数值完全相同、只是皮肤不同的武器合并为一行；名字不同的即使数值相同也分开登记。
- 传说级统一记为 Lv.15。

## 字段说明

见 `weapons.json` 的 `columns`。常见字段包括：系列、武器名、武器类型、等级、伤害、射速、精度、稳定、跑动、穿甲、射程、换弹、弹匣容量、备弹数量、英雄/生化/破甲打击、迷宫相关、特殊属性、技能、**芯片效果**、击败特效等。

`芯片效果` 来自天赋「属性加成」中的武器芯片词条（如「步枪精度+4%」）；有对应芯片的武器写入效果文案，其余为「无」。原始对照表见 `chips.json` / `chips.csv`。

## 使用

直接读取 `weapons.json` 中的 `weapons` 数组即可。
